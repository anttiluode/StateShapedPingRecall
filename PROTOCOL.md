# State-shaped pings: a bounded recall pilot

Written before running the scientific batch, 15 November 2026. This is an exploratory assay, not a new production node or a preregistered biological study.

Question: does adding a local-history-dependent pulse shape to the existing PerceptionLabAI growth system make a single cue reconstruct a missing learned sequence?

Use unchanged upstream WaveFieldNode (96x96, speed .5, four substeps), unchanged fade triggers and GrowingReturnNode. Three units, eight candidate returns each. Existing growth parameters: budget 1, learning rate .2, trace decay .97, pruning .02. No hardening. Each body learns only ABC or ACB, at sites 0,7,4. Twenty 400-frame episodes; rebuild all nodes between episodes, carrying only weights/alive flags. Probe from a full activity wipe with growth disabled. No classifier, fitted output weights, target signal, or scheduled missing event enters the recall run.

Twelve independently seeded training schedules, paired across two histories and four payload conditions. Schedules vary gap 28..42, amplitude .90..1.12, onset +/-5 and training gap +/-3. Probe uses a fresh onset offset and amplitude 1, and the nominal gap sets scoring targets only. One separate development seed runs two training episodes for plumbing only. No tuning on scientific results.

Conditions: original one-frame .24 impulse; fixed two-frame [.192,.048]; fixed reverse [.048,.192]; state-shaped choosing between those two shapes by whether the preceding 50 samples' variance exceeds their squared mean (equivalently variance/mean-square > .5). Samples are the signed local wave input. Shape is deliberately a two-symbol toy code, not a fit to biological spikes. Both shapes have identical area .24 and squared-drive sum .039168; their centroids differ .6 frame. Original impulse has equal area but higher squared-drive sum .0576. Learning occurs once per original spike; the second payload sample cannot cause another growth update. Connections are frozen during each two-frame emission.

Target: passive wave generated by the full sequence minus passive wave generated by A alone. Prediction: active A-only wave minus passive A-only wave. Measure signed time series at all eight apertures from two frames after the first missing event through 100 frames after the second. No gain fit, lag search, or rectification. Score = 1 - squared prediction error / target squared norm; 0 is the passive-cue baseline, 1 perfect reconstruction, negative worse. Compare own versus opposite-order target using the same output. This is sampled waveform recall, not a full-field reconstruction claim.

Controls: no-growth uniform returns, shuffled branch destinations, silent cue, and for state-shaped bodies a replay with the same spike onsets and per-unit shape counts but shapes permuted between events. Replay explicitly holds timing fixed, so it diagnoses payload alignment only, not the total closed-loop role of shapes. Preserve original results even if negative. Save clipping, spike counts, shape variation and structures. A perfect target replay checks scoring sensitivity, not learning.

Provisional success requires median score > .10, own-order preference in >=18/24 bodies, and state-shaped improvement over each fixed-shape condition with positive seed-clustered 95% bootstrap lower bound; also outperform no-growth and scrambled-structure controls. Payload-specific evidence additionally requires degradation under shape permutation; if too few/identical payloads prevent a meaningful permutation, say the causal test is inconclusive. This small pilot is a gate, not proof of necessity or biological mechanism. A failed assay rejects only this encoding with this growth rule and task.

Stronger inverse-model test remains separate: infer hidden source parameters from partial sensors and use them to predict withheld sensors under interventions. Sequence replay alone cannot establish that.
